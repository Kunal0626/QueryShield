# Format: one signature per line, "weight|pattern".
#   - weight: integer used by the v3 scoring detector (Phase 6). The v1/v2
#     detectors ignore it and block on ANY match.
#   - pattern: matched against the LOWERCASED (v1) or fully NORMALIZED (v2/v3)
#     field value, so patterns are written lowercase.
# Lines starting with '#' and blank lines are ignored.
#
# These are intentionally literal substrings; structure that needs context
# (a quote followed by a comment, a bare tautology) is handled by the Phase 6
# tokenizer rules instead, not by widening these into false-positive machines.
# A few low-precision signatures (--, 0x, '=') are kept on purpose: they show
# the precision problem that the Phase 6 rules then fix in the before/after.
